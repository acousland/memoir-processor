# Memoir Processor 1.1.0

- Correct track alignment and order-independent echo deduplication.
- Repaired diarization decoding, restart recovery, retry policy, and cancellation.
- Authenticated, bounded upload streaming and validated session paths.
- Isolated, version-pinned optional Python diarization runtime.
- Sparkle updates, Developer ID signing, and Apple notarization.

Requires macOS 15 or later and Apple Silicon. Basic transcription uses local WhisperKit models. Speaker identification remains optional and requires a separate runtime and Hugging Face model access.
